# D6：命令行环境与持久配置

## 1. 三种“让任务继续”的方式

| 方式 | 实际行为 | 能否重新接回界面 |
|---|---|---|
| `命令 &` | 启动时直接放到后台运行 | 不能接回原来的前台界面 |
| `Ctrl-Z`，再输入 `bg` | 先暂停前台任务，再让它在后台继续 | 可用 `fg` 拉回前台 |
| tmux 中 detach | 离开 tmux 界面，但会话和其中任务继续存在 | 可用 `tmux attach` 接回 |

`Ctrl-Z` 是暂停，不是终止。普通后台任务不等于可重连会话；tmux 也不能让任务在电脑或 WSL 关闭后继续运行。
