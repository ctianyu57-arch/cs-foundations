# D3 Shell Tools

## 理解问答

1. cleanup.sh 解决什么问题？

答案：它把指定目标目录当前这一层的文件按扩展名分类到不同文件夹，不删除文件，也不整理子目录。

2. dry-run 和正式运行有什么区别？

答案：dry-run 只打印移动计划，不修改文件；正式运行才会实际创建分类目录并移动文件。

3. 为什么脚本里的文件路径变量要加双引号？

答案：双引号能防止包含空格的文件路径被 Shell 拆成多个参数，确保命令处理的是完整文件名。

4. 哪项测试证明脚本没有递归整理子目录？

答案：正式运行后，nested/keep.pdf 仍在原处，证明脚本只整理当前层，没有递归处理子目录。

5. 重复运行时，退出码和文件总数分别是多少？这说明什么？

答案：退出码是 0，文件总数仍是 6，说明脚本再次执行也能正常结束，没有丢失文件或制造副本，具有可重复执行性。
